# Sport Tracker

אפליקציית מעקב ספורט אישית בעברית, מותאמת לטלפון וניתנת להתקנה כאפליקציית PWA.

## תכונות
- מעקב אחרי מתח, שכיבות סמיכה, סקוואטים, פלאנק, משקל גוף ומדדים אישיים.
- רישום ריצה עם מרחק בקילומטרים וזמן בדקות ובשניות באותה מדידה.
- גרפים נפרדים למרחק ולזמן ריצה, שיא אישי והשוואה למדידה הראשונה.
- היסטוריית מדידות וייצוא CSV.
- שמירה מקומית אוטומטית באמצעות IndexedDB ו-localStorage.
- Service Worker לעבודה לאחר טעינה ראשונה גם ללא חיבור לאינטרנט.

## פרסום ב-GitHub Pages
המאגר כולל GitHub Actions workflow לפרסום אוטומטי. בפעם הראשונה יש להיכנס ל:
**Settings → Pages → Build and deployment → Source → GitHub Actions**.
לאחר מכן כל push לענף main יפרסם גרסה חדשה.

כתובת האתר הצפויה: https://akonstv45-droid.github.io/sport-tracker/

## פרטיות
המדידות נשמרות מקומית בדפדפן במכשיר המשתמש. אין שרת, חשבון משתמש או סנכרון בין מכשירים. מומלץ לייצא CSV כגיבוי.
